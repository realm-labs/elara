# Elara Codex Goal

Status: Draft 9
Purpose: store the tiny reusable `/goal` prompt. All operational detail lives in
referenced docs.

## Prompt To Paste

```text
/goal Read docs/CODEX_WORKFLOW.md, then continue Elara from docs/PROGRESS.md until docs/MILESTONES.md is complete.
```

## Reference Boundary

Do not paste milestone, architecture, workflow, or Lua source-reference detail
into `/goal`. Keep those details in `docs/CODEX_WORKFLOW.md`,
`docs/PROGRESS.md`, `docs/MILESTONES.md`, and `docs/ARCHITECTURE.md`.
